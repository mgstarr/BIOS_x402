How it works

Three steps. One HTTP request, retried once.

1

Agent asks → gets a 402 bill

The agent calls /api/price?symbol=ETH. We answer 402 Payment Required with the price, token and our wallet in the PAYMENT-REQUIRED header.

2

Agent pays with a signature

The agent's wallet signs a USDC transfer for exactly that amount and retries the same request with a PAYMENT-SIGNATURE header. No gas, no sign-up.

3

Agent gets the data

We verify and settle the payment, then return 200 with the data plus a PAYMENT-RESPONSE receipt holding the transaction hash.
