Overview

An AI agent that pays for data, and a guard that keeps it honest

The agent buys data from web shops with real USDC on a local copy of Base Sepolia. AI can be tricked by a dishonest shop. The guard can't, because it checks every bill against the owner's rules before any signature exists.

1

The agent asks

A task such as "price and mood for Ether". The agent picks what to buy.

2

The seller bills

The shop answers HTTP 402 with a bill: amount, wallet, token, time limit.

3

The guard checks

Eight plain rules. One failure and the bill is refused, nothing is signed.

4

Money moves

Only allowed bills are signed and settled on-chain. The shop gets paid.

Demo in five steps

Open each view in its own window, side by side.
1Honest purchase. On the Guard page, run the task "What is the price and market mood for Ether?". The guard allows both bills and TickToll gets an invoice for each.
2Attack with the guard on. On the Attacker page, launch Overcharge. The Guard page shows it blocked: the price is 95 times the usual one. Nothing is signed.
3Switch the guard off and launch the same attack. The agent pays 95 cents to the attacker, on-chain, with a transaction ID.
4Build a new attack the guard has never seen, and change the owner's rules on the Guard page to see the verdicts change.
5Test all. Every attack with the guard on and off: on stops all of them, off loses money, and honest purchases go through either way.
